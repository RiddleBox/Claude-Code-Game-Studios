# F1 窗口系统 - 技术债务与迭代计划

## 🔴 高优先级技术债

### 1. 背景分层系统重构
**问题**：当前单层背景缺乏景深和层次感，视觉效果廉价

**影响**：
- 核心体验受损："透过窗口观察异世界"的沉浸感不足
- 视觉质量低于预期标准
- 无法支持后续的视差滚动、景深模糊等高级效果

**解决方案**：
- 实现多层背景系统（5层：远景/中景/房屋结构/室内摆设/窗框）
- 每层独立TextureRect节点，支持独立控制
- 重构背景加载逻辑，支持分层主题资产

**预估工作量**：
- F1代码重构：2-3小时
- 主题01分层重设计：1-2小时
- 分层资产生成：2-3小时
- 测试与调优：1小时

**相关文档**：
- [背景分层系统设计](../../art/background-layering-system.md)

**计划时间**：下一轮F1迭代（MVP后第一轮优化）

## 🟡 中优先级技术债

### 2. 视差滚动效果
**问题**：背景静态，缺少动态空间感

**解决方案**：
- 当角色在房间内移动时，不同层以不同速度移动
- 远景移动最慢（0.1x），近景移动最快（2.0x）

**依赖**：背景分层系统重构完成

**计划时间**：分层系统完成后

### 3. 景深模糊效果
**问题**：所有层清晰度一致，缺少真实的景深感

**解决方案**：
- 使用Godot Shader为远景层添加轻微高斯模糊
- 可选：实现动态焦点系统（焦点外的层模糊）

**依赖**：背景分层系统重构完成

**计划时间**：分层系统完成后

---

## 🟢 低优先级技术债

### 4. 大气透视效果
**问题**：远景色彩与近景一致，缺少空间距离感

**解决方案**：
- 远景层降低饱和度10-15%，增加蓝色调
- 使用Shader实现动态调整

**计划时间**：视觉优化阶段

### 5. 动态光照系统
**问题**：背景光照静态，无法响应时间系统变化

**解决方案**：
- 所有背景层同步调整色温和亮度
- 支持昼夜循环、天气变化

**依赖**：F3时间系统完成

**计划时间**：时间系统集成阶段
