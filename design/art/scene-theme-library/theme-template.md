### Character Expression Examples

**Example for Character Type A（严谨型）**:
- 工具按类别整齐摆放在工具架上
- 每个抽屉有标签
- 工作台清洁，无多余物品
- 装饰极简，只有一盏实用台灯
- 冷色调为主（蓝灰色）

**Example for Character Type B（温馨型）**:
- 桌上有小盆栽（多肉植物）
- 墙上挂着朋友送的画
- 茶具精致，有花纹
- 窗台上有装饰品
- 暖色调为主（米黄/橙色）

**Example for Character Type C（随性型）**:
- 书籍堆叠在桌角（但角色知道每本在哪）
- 工具随手放，但常用的都在手边
- 有未完成的多个项目同时进行
- 装饰品和工具混在一起
- 混合色调，无明确规划

## Element Checklist（元素检查清单）

### 必须有（Mandatory）

- [ ] **角色活动区**：前景有明确的角色站立/坐的位置
- [ ] **空间定义元素**：至少1-2件大型家具定义空间类型
- [ ] **世界观线索**：至少1个元素暗示这是异世界
- [ ] **光源**：明确的光照方向
- [ ] **生活痕迹**：至少2-3个"被使用过"的细节

### 应该有（Recommended）

- [ ] **窗外景色**：远景有异世界的天空/建筑/自然景观
- [ ] **性格线索**：2-3个体现角色性格的物品/布置
- [ ] **叙事钩子**：1-2个可以引发好奇的细节
- [ ] **色彩层次**：前景/中景/远景有明确的色彩层次

### 可选有（Optional）

- [ ] **动态元素暗示**：可以后期添加动画的元素
- [ ] **季节/天气线索**：窗外景色暗示季节或天气
- [ ] **时间线索**：光照角度暗示时间段

## Integration Notes（集成说明）

### Technical Requirements
- **分辨率**：1920×1080（生成），缩放至320×320（引擎使用）
- **文件格式**：PNG，透明背景（如需）
- **文件大小**：<2MB
- **命名规范**：`bg_[theme-id]_[state].png`（如 `bg_theme01_normal.png`）

### Engine Integration
- **加载位置**：P1 主界面 UI，Layer 2 背景层
- **外出态支持**：需支持 `modulate` 变暗至20%亮度
- **泄漏内容叠加**：需有足够留白区域（建议上方1/3或侧边）

### Variant Needs
