## 文档定位

本文档用于追踪 VS Pre-Production 第一轮样例美术资产拆分。

这不是最终美术规范，也不是正式资源尺寸标准。当前目标是从概念图逆向重建一套最小可验证的 Scene Kit，用于确认核心观感是否成立。

参考图：

- `D:/AIProjects/ArtResource/ArtRef/桌宠效果_参考_满意.png`

核心定义：

> 不做普通抠图、裁切或平面拆图。按可复用 Scene Kit 重建资源。每个关键资产都应是完整图层，隐藏区域需要补全，适合 Godot 中缩放、遮罩、局部显示、视差与后续替换。

---

## 核心原则

- 目标是 Asset Reconstruction，不是 image slicing。
- 第一轮只验证核心观感：窗、房间、角色、前景遮挡、玻璃氛围。
- `320x320` 只作为 Godot 当前观察窗口或裁切测试窗口，不是源资产尺寸。
- 背景与遮罩使用高分辨率母版，后续再在 Godot 中缩放和局部显示。
- `Interior_Room_Frame_Occluder` 必须能遮住矩形窗外图，只露出圆窗区域。
- 角色、前景植物、玻璃氛围等应透明 PNG。
- P0 不追求完整资源管线，只追求“味道是否对”。

## P0 图层顺序

```text
0 Exterior_Window_View_Combined
1 Interior_Room_Frame_Occluder
2 Desk_Base
3 Character_Writing
4 Foreground_Plants
5 Glass_Atmosphere
```

说明：

- `Exterior_Window_View_Combined` 是底层矩形窗外图。
- `Interior_Room_Frame_Occluder` 负责遮住矩形外景，只让圆窗区域可见。
- `Desk_Base`、`Character_Writing`、`Foreground_Plants` 建立室内生活与窥视距离。
- `Glass_Atmosphere` 位于顶层，用于表达连接阻隔。

## P2 暂缓清单

| 暂缓资产 | 暂缓原因 |
|---|---|
| `Shelf_Left` / `Shelf_Right` | 第一轮不是完整房间管线 |
| 细分书本、纸张全集 | 先验证桌面整体生活感 |
| 角色头发、眼睛、手部分件 | 先不进入动画和换装复杂度 |
| 完整角色动画帧 | 第一轮一个高质量写字静帧足够 |
| 天气系统 | 先用窗外合成图和玻璃层验证氛围 |
| 多个窗外地点 | P0 只需要一个有吸引力的窗外世界 |
| UI 状态提示 | 连接状态应由玻璃、光、清晰度表达 |
| 地面、路径、移动资源 | 与当前核心体验无关 |

## Godot 验证项

| 验证项 | 观察重点 |
|---|---|
| 窗是否成为核心 | 玩家第一眼是否感到“我在通过窗口看另一个世界” |
| 外景吸引力 | 只露出圆窗区域时，窗外是否仍有想象空间 |
| 遮罩稳定性 | 矩形外景是否被室内遮罩完整盖住 |
| 角色非表演性 | 她是否像在写自己的东西，而不是摆拍给玩家看 |
| 生活感 | 桌面、书写姿态、暗部室内是否共同建立日常感 |
| 前景窥视感 | 植物遮挡是否增强距离，而不是妨碍阅读画面 |
| 玻璃连接感 | 顶层玻璃是否表现“遥远连接”，而不是故障或 UI 特效 |
| 小窗裁切 | `320x320` 裁局部时，仍能读到窗、她、生活痕迹或氛围 |
| 后续可扩展性 | P0 成立后，是否自然支持拆外景视差、桌面道具和角色姿态 |
