# Visual Design System: 窗语（Window Whisper）

*Created: 2026-04-21*
*Status: Active*

---

## 设计理念

本文档定义了《窗语》的视觉质量标准体系。我们的目标不是追求技术上的"完美",而是创造**氛围正确、情感到位**的视觉体验。

### 核心原则

1. **氛围优先于细节** - 整体感觉比局部精度更重要
2. **一致性优于多样性** - 统一的风格语言比丰富的变化更关键
3. **情感共鸣优于视觉冲击** - 温暖治愈比炫目华丽更符合游戏定位
4. **可迭代性** - 标准会随首批素材测试结果调整

## 背景场景质量标准矩阵

背景场景需要营造"透过小窗窥视异世界"的氛围感,同时不干扰玩家的工作注意力。

### 维度定义与量化指标

| 维度 | 最低可接受 (MVP) | 理想目标 (Polish) | 提升路径 |
|------|-----------------|------------------|---------|
| **1. 氛围营造** | 能明确传达场景类型(室内/室外/时间段),色调符合情绪基调 | 玩家瞥一眼就能感受到情绪(温暖/宁静/神秘),细节支撑氛围 | 增强光影对比 → 添加氛围粒子(灰尘/光斑) → 微妙动态元素 |
| **2. 层次分离** | 前景/中景/背景在视觉上可区分,不混成一团 | 清晰的景深感,每层有独立的视觉重量,支持视差滚动 | 调整对比度差异 → 添加边缘模糊 → 色温分层(近暖远冷) |
| **3. 色彩和谐** | 使用调色板内的颜色,无明显冲突 | 色彩关系精心编排,支撑情绪表达,与角色形成互补 | 统一色温 → 降低饱和度 → 建立主色调-强调色关系 |
| **4. 纸质感** | 可见纸质纹理,不过度抢眼 | 纹理强度恰到好处,增强手绘温暖感但不破坏画面 | 调整纹理不透明度(15-25%) → 匹配纹理缩放 → 局部强化(边缘) |
| **5. 边缘处理** | 边缘自然柔和,无生硬矢量感 | 水彩晕染效果明显,边界有呼吸感,符合"窥视碎片"的设定 | 增加边缘羽化 → 添加色彩溢出 → 不规则边界变化 |
| **6. 信息清晰度** | 关键元素(门/窗/家具)可辨识,不模糊成一片 | 视觉引导明确,玩家能快速理解空间关系和功能区域 | 提升关键元素对比度 → 简化次要细节 → 添加视觉焦点(光源/色块) |

### 量化评分标准 (1-5 分制)

#### 维度 1: 氛围营造

**评分依据**:
- **1 分 (不合格)**: 无法判断场景类型或时间段,色调混乱或与情绪基调冲突
  - 案例: 温馨卧室场景使用冷灰色调,无光源,感觉阴冷
- **2 分 (勉强可用)**: 能判断场景类型,但情绪传达模糊,需要仔细观察才能理解
  - 案例: 室内场景有窗户和家具,但光线平淡,缺乏情绪感染力
- **3 分 (最低可接受)**: 场景类型明确,色调符合情绪基调,但缺乏细节支撑
  - 案例: 温暖卧室有暖色调和窗户光线,但缺少阴影和氛围细节
  - 量化指标: 光源方向明确,主色调与情绪匹配,对比度比 ≥ 2:1
- **4 分 (良好)**: 情绪传达清晰,光影细节丰富,玩家能快速感受到氛围
  - 案例: 温暖卧室有柔和阳光、地板阴影、窗帘透光,营造宁静感
  - 量化指标: 有明确光源 + 阴影,细节层次 ≥ 3 层,色温统一
- **5 分 (理想目标)**: 瞥一眼就能感受到强烈情绪,细节完美支撑氛围,有微妙动态元素
  - 案例: 温暖卧室有动态光斑、漂浮灰尘、窗帘轻微飘动,沉浸感极强
  - 量化指标: 动态元素 ≥ 1 个,氛围粒子存在,玩家 3 秒内能说出情绪关键词

**测试方法**:
1. 5 秒快速测试: 显示场景 5 秒后隐藏,询问测试者"这是什么地方?什么时间?什么感觉?"
2. 情绪关键词测试: 提供 10 个情绪词(温暖/冷清/神秘/活泼/压抑等),测试者选择最匹配的 3 个
3. 对比测试: 与参考图(已知高质量场景)并排显示,判断氛围强度差异

#### 维度 2: 层次分离

**评分依据**:
- **1 分 (不合格)**: 前中后景混成一团,无法区分层次,视觉扁平
  - 案例: 所有元素对比度相同,无景深,像贴纸拼贴
- **2 分 (勉强可用)**: 能勉强区分 2 层,但边界模糊,层次感弱
  - 案例: 前景和背景有轻微对比度差异,但中景缺失或不明显
- **3 分 (最低可接受)**: 前中后景可区分,但层次感不强,需要仔细观察
  - 案例: 三层对比度有差异,但色温和模糊度相同
  - 量化指标: 三层对比度差异 ≥ 15%,灰度模式下可区分
- **4 分 (良好)**: 层次清晰,有明显景深感,每层视觉重量独立
  - 案例: 远景模糊 + 低饱和,中景清晰,近景高对比,层次分明
  - 量化指标: 对比度差异 ≥ 30%,远景模糊半径 ≥ 2px,色温差异 ≥ 200K
- **5 分 (理想目标)**: 完美景深,支持视差滚动,色温分层明显,有空间纵深感
  - 案例: 远景冷色调 + 高模糊,近景暖色调 + 清晰,视差移动时层次感极强
  - 量化指标: 色温差异 ≥ 500K,模糊梯度平滑,视差速度比 ≥ 1:2:4

**测试方法**:
1. 灰度测试: 转为灰度模式,三层应有明显亮度差异(测量 RGB 平均值差异 ≥ 30)
2. 模糊测试: 高斯模糊 5px 后,层次边界应仍可辨识
3. 视差模拟: 在 Godot 中设置不同 parallax 速度,观察层次分离效果

#### 维度 3: 色彩和谐

**评分依据**:
- **1 分 (不合格)**: 使用调色板外的颜色,或颜色冲突明显,刺眼不适
  - 案例: 温暖场景中突然出现纯蓝或纯绿,饱和度过高
- **2 分 (勉强可用)**: 颜色在调色板内,但搭配不当,缺乏和谐感
  - 案例: 所有颜色饱和度相同,缺乏主次关系,视觉疲劳
- **3 分 (最低可接受)**: 使用调色板颜色,无明显冲突,但缺乏精心编排
  - 案例: 颜色正确但平淡,缺少强调色,情绪表达不足
  - 量化指标: 色相范围 ≤ 120°,饱和度范围 ≤ 40%,色温统一(±300K)
- **4 分 (良好)**: 色彩关系清晰,有主色调和辅助色,支撑情绪表达
  - 案例: 60% 米白 + 30% 天蓝 + 10% 橙黄,层次分明,情绪到位
  - 量化指标: 主色占比 50-70%,辅助色 20-40%,强调色 5-15%
- **5 分 (理想目标)**: 色彩编排完美,与角色形成互补,情绪表达精准,长时间观看舒适
  - 案例: 色彩比例精确,强调色位置精心设计,与角色色彩呼应
  - 量化指标: 色彩对比度符合 WCAG AA 标准,饱和度梯度平滑,无视觉疲劳

**测试方法**:
1. 色轮分析: 在 Photoshop/GIMP 中提取主要颜色,绘制在色轮上,检查分布
2. 饱和度直方图: 检查饱和度分布,应集中在 40-70% 区间,避免极端值
3. 长时间测试: 显示场景 5 分钟,询问测试者是否感到视觉疲劳或不适

#### 维度 4: 纸质感

**评分依据**:
- **1 分 (不合格)**: 无纸质纹理,或纹理过强破坏画面,或纹理不匹配
  - 案例: 完全平滑无纹理,或纹理强度 > 50% 导致画面脏乱
- **2 分 (勉强可用)**: 有纸质纹理,但强度不当或缩放不匹配
  - 案例: 纹理过弱(< 10%)几乎不可见,或过强(> 35%)抢夺注意力
- **3 分 (最低可接受)**: 纸质纹理可见但不抢眼,强度适中
  - 案例: 纹理强度 15-25%,近距离观察可见,远看融入画面
  - 量化指标: paper_strength = 0.15 ~ 0.25,纹理颗粒大小适中
- **4 分 (良好)**: 纹理强度恰到好处,缩放匹配,增强手绘温暖感
  - 案例: 纹理在不同尺寸素材上视觉一致,颗粒大小自然
  - 量化指标: paper_scale 根据素材尺寸调整,512px 用 2.0,1024px 用 4.0
- **5 分 (理想目标)**: 纹理有层次,边缘和高光区域强化,暗部减弱,完美融入画面
  - 案例: 使用 luminance-based masking,纹理强度随亮度变化
  - 量化指标: 亮部纹理强度 × 1.5,暗部 × 0.7,过渡平滑

**测试方法**:
1. 缩放测试: 在 100%/50%/25% 缩放下观察,纹理应在 100% 时可见,50% 时融入
2. 对比测试: 关闭纹理 vs 开启纹理,应有明显温暖感差异但不破坏画面
3. 一致性测试: 多个素材并排显示,纹理强度和颗粒大小应视觉一致

#### 维度 5: 边缘处理

**评分依据**:
- **1 分 (不合格)**: 边缘生硬,有明显矢量感或锯齿,破坏手绘风格
  - 案例: 边缘完全清晰,像 AI 默认输出,无任何柔化处理
- **2 分 (勉强可用)**: 边缘有轻微柔化,但不够自然,仍有数字感
  - 案例: 均匀模糊 1-2px,但缺乏水彩晕染的有机感
- **3 分 (最低可接受)**: 边缘自然柔和,无生硬矢量感,有基础水彩感
  - 案例: edge_softness = 0.02 ~ 0.05,边缘柔和但形状清晰
  - 量化指标: 边缘羽化半径 2-5px,alpha 渐变平滑
- **4 分 (良好)**: 水彩晕染效果明显,边缘有色彩溢出,呼吸感强
  - 案例: 边缘颜色向外轻微扩散,模拟真实水彩晕染
  - 量化指标: 色彩溢出范围 3-8px,溢出颜色饱和度降低 30-50%
- **5 分 (理想目标)**: 边界有不规则变化,像真实手绘,完美符合"窥视碎片"设定
  - 案例: 使用 noise texture 调制边缘,创造有机的起伏变化
  - 量化指标: 边缘变化频率 0.1-0.3 cycles/px,振幅 1-3px

**测试方法**:
1. 放大测试: 放大到 200%,边缘应柔和渐变,无锯齿或生硬线条
2. 对比测试: 与真实水彩画边缘对比,应有相似的有机感和不规则性
3. 动态测试: 在不同背景前显示,边缘应自然融入,无明显"抠图感"

#### 维度 6: 信息清晰度

**评分依据**:
- **1 分 (不合格)**: 关键元素模糊不清,无法辨识功能,空间关系混乱
  - 案例: 门窗家具与背景对比度过低,玩家无法快速理解场景
- **2 分 (勉强可用)**: 关键元素勉强可辨识,但需要仔细观察,视觉引导不明确
  - 案例: 门窗可见但不突出,玩家需要 10 秒以上才能理解空间布局
- **3 分 (最低可接受)**: 关键元素可辨识,不模糊成一片,基本空间关系清晰
  - 案例: 门窗家具清晰,玩家 5 秒内能理解场景布局
  - 量化指标: 关键元素对比度 ≥ 3:1,边缘清晰度 ≥ 80%
- **4 分 (良好)**: 视觉引导明确,玩家能快速理解空间关系和功能区域
  - 案例: 关键元素对比度高,次要细节简化,视觉焦点清晰
  - 量化指标: 关键元素对比度 ≥ 4.5:1,识别时间 ≤ 3 秒
- **5 分 (理想目标)**: 完美视觉引导,光源和色块精心设计,玩家视线自然被引导到重要区域
  - 案例: 使用光源、色彩对比、细节密度引导视线,玩家瞬间理解场景
  - 量化指标: 视觉焦点对比度 ≥ 7:1,视线追踪测试 90% 用户首先看向焦点区域

**测试方法**:
1. 快速识别测试: 显示场景 3 秒,询问"有哪些重要物体?",正确率应 ≥ 80%
2. 视线追踪: 使用眼动仪或观察测试者视线,首次注视点应在关键元素上
3. 功能理解测试: 询问"角色可能在哪里活动?",测试者应能快速指出功能区域

### 场景类型特殊要求

#### 室内场景(角色房间/朋友家)

**必需元素**
- **光源**: 必须有明确光源(窗户/灯具),支撑光影逻辑
  - 窗户光: 方向性强,产生明显阴影,色温偏暖(3000-4000K)
  - 灯具光: 点光源,范围有限,色温可调(2700-5000K)
  - 环境光: 柔和均匀,填充阴影,避免过度对比
- **空间感**: 透视合理,不过度夸张也不过于扁平
  - 一点透视: 适用于正面房间,消失点在画面中心
  - 两点透视: 适用于角落视角,消失点在画面两侧
  - 透视角度: 建议 15-30°,避免极端仰视或俯视
- **生活感**: 适量道具暗示居住者性格,但不杂乱
  - 道具数量: 3-8 个功能性道具 + 2-5 个装饰性道具
  - 摆放逻辑: 符合使用习惯(书在书架/床头,杯子在桌上)
  - 性格暗示: 整洁=有序性格,杂乱=随性性格,书多=知识型

**空间比例参考**
- 墙面:地板:天花板 = 3:4:1 (标准房间)
- 窗户占墙面 20-40% (充足采光)
- 家具占地板 30-50% (不拥挤也不空旷)
- 留白空间 ≥ 30% (视觉呼吸空间)

**光影逻辑检查**
- [ ] 光源方向一致(所有阴影指向同一方向)
- [ ] 阴影长度合理(光源角度 45° 时,阴影长度约为物体高度)
- [ ] 阴影柔和度匹配光源(窗户光=柔和阴影,灯具光=清晰阴影)
- [ ] 反射光存在(地板/墙面有轻微反射,避免纯黑阴影)

**常见问题与解决**
- 问题: 房间感觉压抑,空间狭小
  - 解决: 提高天花板,增加窗户面积,使用浅色墙面
- 问题: 房间感觉空旷,缺乏生活感
  - 解决: 添加 2-3 个中型道具(椅子/书架/植物)
- 问题: 透视不自然,物体变形
  - 解决: 检查消失点位置,确保所有平行线汇聚到同一点

#### 室外场景(花园/街道/自然)

**必需元素**
- **天空处理**: 天空占比 30-50%,渐变自然,支撑时间段氛围
  - 清晨(6-8 点): 粉橙渐变,地平线明亮,天顶偏紫
  - 正午(11-13 点): 蓝白渐变,天顶最亮,地平线偏白
  - 黄昏(17-19 点): 橙红渐变,地平线火红,天顶偏蓝紫
  - 夜晚(20-5 点): 深蓝渐变,可见星星,地平线偏黑
- **景深**: 远景明显模糊/低饱和,强化"窗口"的距离感
  - 近景(0-5m): 清晰,饱和度 100%,对比度 100%
  - 中景(5-20m): 轻微模糊,饱和度 70-80%,对比度 70-80%
  - 远景(20m+): 明显模糊,饱和度 40-60%,对比度 50-60%
- **自然元素**: 植物/云朵等有机形态,边缘柔和
  - 植物: 叶片边缘不规则,有自然起伏,避免对称
  - 云朵: 边缘柔和渐变,形状有机,避免几何规则
  - 水面: 反射柔和,有轻微波纹,避免镜面效果

**地平线位置参考**
- 上 1/3 (66% 高度): 强调地面,适合花园/街道场景
- 中间 (50% 高度): 平衡天地,适合开阔自然场景
- 下 1/3 (33% 高度): 强调天空,适合日落/星空场景
- 避免: 正中间(50%)容易显得呆板,建议偏移 ±10%

**大气透视参考**
- 每 10m 距离: 饱和度降低 10%,对比度降低 10%
- 色温偏移: 远景偏冷(+200K/10m),近景偏暖
- 细节密度: 远景简化 50%,只保留轮廓和大色块

**常见问题与解决**
- 问题: 天空渐变不自然,有明显色带
  - 解决: 增加渐变步数,使用 dithering,添加轻微噪点
- 问题: 远景过于清晰,缺乏距离感
  - 解决: 应用高斯模糊 3-8px,降低饱和度 30-50%
- 问题: 植物边缘生硬,缺乏有机感
  - 解决: 增加边缘羽化,添加色彩溢出,使用 noise 调制

#### 特殊场景(梦境/回忆/事件)

**设计原则**
- **色彩偏移**: 允许偏离标准调色板,但保持和谐
  - 梦境: 色相偏移 ±30-60°,饱和度提高 20-30%,营造超现实感
  - 回忆: 降低饱和度 30-50%,添加暖色滤镜,营造怀旧感
  - 事件: 使用强调色,对比度提高 30-50%,营造戏剧感
- **抽象化**: 可简化细节,强调情绪符号
  - 简化程度: 保留 30-50% 细节,其余用色块/符号代替
  - 情绪符号: 心形=爱,星星=梦想,阴影=恐惧,光芒=希望
  - 几何化: 将有机形态简化为几何形状,但保持可辨识
- **过渡标记**: 与常规场景有明确视觉区分(色调/纹理/边缘)
  - 色调: 至少偏移 30°,或使用非常规色温(极暖/极冷)
  - 纹理: 可使用不同纹理(如梦境用更粗糙纹理,回忆用褪色纹理)
  - 边缘: 可使用不同边缘处理(如梦境用更模糊边缘,事件用更清晰边缘)

**梦境场景特殊要求**
- [ ] 色彩饱和度高于常规场景 20-30%
- [ ] 物体比例可不合理(如巨大的花朵,微小的房屋)
- [ ] 重力可违反(漂浮物体,倒置场景)
- [ ] 边缘更模糊,有光晕效果
- [ ] 可见超现实元素(多个月亮,彩色星星,会说话的物体)

**回忆场景特殊要求**
- [ ] 整体降低饱和度 30-50%,营造褪色感
- [ ] 添加暖色滤镜(色温 +500-1000K)
- [ ] 边缘有轻微模糊,像老照片
- [ ] 可添加纸质纹理强化(paper_strength × 1.5)
- [ ] 可见怀旧元素(泛黄边缘,轻微划痕,暗角效果)

**事件场景特殊要求**
- [ ] 使用强调色,对比度提高 30-50%
- [ ] 光源更戏剧化(强烈侧光,逆光,聚光灯效果)
- [ ] 角色更突出,背景更简化
- [ ] 可使用特效(光芒,粒子,速度线)
- [ ] 视觉焦点极其明确(对比度 ≥ 7:1)

**过渡动画建议**
- 常规 → 梦境: 色彩饱和度渐变(1 秒),边缘模糊渐变(0.5 秒)
- 常规 → 回忆: 饱和度降低(1 秒),暖色滤镜淡入(0.5 秒),纸质纹理强化(0.5 秒)
- 常规 → 事件: 背景模糊(0.3 秒),角色高光(0.2 秒),对比度提升(0.5 秒)

**常见问题与解决**
- 问题: 特殊场景过于夸张,破坏整体风格
  - 解决: 保持水彩手绘语言,只调整色彩/对比度,不改变基础风格
- 问题: 玩家无法区分特殊场景和常规场景
  - 解决: 增强视觉区分度,至少 2 项明显不同(色调+纹理,或色调+边缘)
- 问题: 过渡动画突兀,玩家感到不适
  - 解决: 延长过渡时间到 1-2 秒,使用缓入缓出曲线

### 背景场景提升路径详解

#### 维度 1: 氛围营造

**Level 1 → Level 2: 增强光影对比**
- **操作**: 在 AI 提示词中添加明确的光源描述
- **示例**: "warm sunlight streaming through window, creating soft shadows on the floor"
- **技术**: 在 Godot 中使用 Light2D 节点增强局部光照
- **验证**: 关闭光源后场景应明显失去情绪感

**Level 2 → Level 3: 添加氛围粒子**
- **操作**: 添加漂浮灰尘、光斑、雨滴等动态元素
- **示例**: GPUParticles2D + 慢速运动 + 低不透明度(10-20%)
- **技术**: 使用 CanvasItemMaterial 的 blend_mode = Add 实现光斑效果
- **验证**: 粒子应增强氛围但不抢夺注意力

**Level 3 → Polish: 微妙动态元素**
- **操作**: 窗帘轻微飘动、植物叶片摇曳、水面波纹
- **示例**: AnimationPlayer 控制 Sprite2D 的 position/rotation,周期 3-5 秒
- **技术**: 使用 Tween + ease_in_out 实现自然节奏
- **验证**: 动态元素应在 5 秒内被注意到,但不干扰工作

#### 维度 2: 层次分离

**Level 1 → Level 2: 调整对比度差异**
- **操作**: 远景降低对比度 30-50%,近景保持 100%
- **示例**: 使用 CanvasItemMaterial 的 modulate 属性调整
- **技术**: 远景 modulate = Color(0.8, 0.8, 0.8, 1.0)
- **验证**: 三层在灰度模式下应有明显区分

**Level 2 → Level 3: 添加边缘模糊**
- **操作**: 远景使用高斯模糊,中景轻微模糊,近景清晰
- **示例**: 在 AI 生成时添加 "background out of focus, bokeh effect"
- **技术**: 或在 Godot 中使用 BackBufferCopy + 模糊 Shader
- **验证**: 模糊应模拟真实景深,不是简单降低清晰度

**Level 3 → Polish: 色温分层**
- **操作**: 远景偏冷(蓝调),近景偏暖(黄调)
- **示例**: 远景 modulate 添加轻微蓝色 tint,近景添加轻微橙色 tint
- **技术**: 使用 ColorRect + CanvasModulate 分层控制
- **验证**: 色温差异应微妙,不破坏整体色彩和谐

#### 维度 3: 色彩和谐

**Level 1 → Level 2: 统一色温**
- **操作**: 确保所有颜色偏向同一色温(暖/冷/中性)
- **示例**: 白天场景统一偏暖,夜晚场景统一偏冷
- **技术**: 在 AI 提示词中明确 "warm color temperature" 或 "cool color temperature"
- **验证**: 使用色温检测工具,所有颜色应在 ±500K 范围内

**Level 2 → Level 3: 降低饱和度**
- **操作**: 整体饱和度控制在 40-70%,避免过度鲜艳
- **示例**: 在 Photoshop/GIMP 中使用 HSL 调整,降低 S 通道 20-30%
- **技术**: 或在 Godot 中使用 ColorRect + Shader 全局降饱和
- **验证**: 场景应柔和舒适,长时间观看不疲劳

**Level 3 → Polish: 建立主色调-强调色关系**
- **操作**: 60% 主色调(背景基底) + 30% 辅助色 + 10% 强调色(视觉焦点)
- **示例**: 米白背景 + 天蓝中景 + 橙黄光源/道具
- **技术**: 在 AI 提示词中明确色彩比例 "predominantly warm beige, accents of soft blue, small pops of orange"
- **验证**: 强调色应立即吸引视线,但不超过画面 10%

#### 维度 4: 纸质感

**Level 1 → Level 2: 调整纹理不透明度**
- **操作**: 纸质纹理叠加强度控制在 15-25%
- **示例**: Shader 参数 paper_strength = 0.15 ~ 0.25
- **技术**: 使用 paper_overlay.gdshader,调整 uniform 参数
- **验证**: 纹理应在近距离观察时可见,远看时融入画面

**Level 2 → Level 3: 匹配纹理缩放**
- **操作**: 纸质纹理的颗粒大小应与画面尺度匹配
- **示例**: 512x512 素材使用 paper_scale = vec2(2.0, 2.0)
- **技术**: 调整 Shader 的 UV 缩放参数
- **验证**: 纹理颗粒应自然,不过大(像素化)也不过小(噪点)

**Level 3 → Polish: 局部强化**
- **操作**: 在边缘/高光区域增强纸质感,暗部减弱
- **示例**: 使用 luminance-based masking,亮度 > 0.7 的区域 paper_strength × 1.5
- **技术**: 在 Shader 中添加 luminance 计算和条件混合
- **验证**: 纸质感应有层次,不是均匀覆盖

#### 维度 5: 边缘处理

**Level 1 → Level 2: 增加边缘羽化**
- **操作**: 使用 edge_softening.gdshader,edge_softness = 0.02 ~ 0.05
- **示例**: 所有背景元素应用边缘柔化 Shader
- **技术**: 在 Sprite2D 的 material 属性中指定 Shader
- **验证**: 边缘应柔和但不模糊,保持形状可辨识

**Level 2 → Level 3: 添加色彩溢出**
- **操作**: 边缘区域颜色向外轻微扩散,模拟水彩晕染
- **示例**: 在 AI 提示词中添加 "watercolor bleeding edges, soft color diffusion"
- **技术**: 或使用自定义 Shader 实现 color bleeding 效果
- **验证**: 溢出应微妙,不破坏形状轮廓

**Level 3 → Polish: 不规则边界变化**
- **操作**: 边缘不是均匀柔化,而是有自然的起伏变化
- **示例**: 使用 noise texture 调制边缘 alpha,创造手绘感
- **技术**: 在 Shader 中叠加 noise 到 alpha 通道
- **验证**: 边缘应有机自然,像真实水彩画

#### 维度 6: 信息清晰度

**Level 1 → Level 2: 提升关键元素对比度**
- **操作**: 门/窗/家具等功能性元素对比度提高 20-30%
- **示例**: 使用 CanvasItemMaterial 的 modulate 单独调整关键元素
- **技术**: 关键元素 modulate = Color(1.2, 1.2, 1.2, 1.0)
- **验证**: 玩家应在 3 秒内识别出所有功能性元素

**Level 2 → Level 3: 简化次要细节**
- **操作**: 装饰性元素降低细节密度,避免视觉噪音
- **示例**: 在 AI 提示词中添加 "simplified decorative elements, minimal details"
- **技术**: 或在后期处理中模糊/降低次要区域的对比度
- **验证**: 次要细节应支撑氛围但不分散注意力

**Level 3 → Polish: 添加视觉焦点**
- **操作**: 使用光源/色块/对比度引导视线到重要区域
- **示例**: 窗户有明亮光线,角色常待的位置有暖色调
- **技术**: 使用 Light2D + 暖色 modulate 创造视觉焦点
- **验证**: 玩家视线应自然被引导到角色活动区域

## 角色质量标准矩阵

角色是玩家情感依附的核心,需要在"可爱讨喜"与"不过度幼稚"之间找到平衡。

### 维度定义

| 维度 | 最低可接受 (MVP) | 理想目标 (Polish) | 提升路径 |
|------|-----------------|------------------|---------|
| **1. 辨识度** | 轮廓清晰,与背景明显区分,关键特征(眼睛/标志物)突出 | 即使缩小到 64px 仍可辨识,剪影独特,一眼认出 | 强化轮廓对比 → 简化形状语言 → 放大关键特征 |
| **2. 表情表现力** | 基础情绪(开心/难过/惊讶)可通过眼睛/嘴巴传达 | 微妙情绪(好奇/思考/无奈)也能清晰表达,表情有层次 | 增加眼睛细节(高光/瞳孔) → 嘴型变化丰富 → 添加次级表情(耳朵/尾巴) |
| **3. 动作流畅度** | 关键帧之间过渡自然,无跳跃感 | 动作有节奏感和重量感,符合角色性格,有次级动作 | 增加中间帧 → 添加缓入缓出 → 身体部件延迟跟随 |
| **4. 风格一致性** | 与背景风格语言统一(几何简化+柔和边缘+纸质感) | 完美融入画面,同时保持视觉焦点地位 | 匹配边缘处理 → 统一纸质纹理强度 → 调整色彩饱和度 |
| **5. 性格传达** | 外形/配色暗示性格倾向(暖色=活泼,冷色=沉静) | 静态姿态和动作节奏都体现性格,玩家能"感觉到"角色是什么样的 | 调整体态(挺拔/慵懒) → 动作速度差异 → 细节装饰(配饰/纹样) |
| **6. 可爱度** | 讨喜不令人反感,符合"治愈"基调 | 可爱但不幼稚,有独特魅力,成年玩家也能接受 | 调整头身比(避免过度Q版) → 眼睛大小适中 → 添加成熟元素(纹理/配饰) |

### 角色与背景对比策略

根据场景需求,角色可以采用两种对比策略:

#### 策略 A: 和谐融入 (Harmonious Integration)

**适用场景**: 
- 日常生活场景(角色在家休息/阅读/睡觉)
- 角色处于放松/平静状态
- 需要营造"归属感"和"宁静感"的时刻
- 玩家工作时的默认状态(陪伴不打扰)

**视觉特征**: 
- 角色色彩与背景呼应,饱和度接近(差异 ≤ 15%)
- 整体和谐,角色像"属于"这个空间
- 对比度适中,角色不过度突出
- 纸质纹理强度一致

**实现方式**:
1. **色彩选择**: 角色主色调从背景调色板中选取
   - 示例: 米白背景 → 角色使用米白/浅棕/淡黄
   - 避免: 背景冷色调时角色使用纯暖色
2. **饱和度匹配**: 角色饱和度 = 背景饱和度 + 10%
   - 示例: 背景平均饱和度 50% → 角色 55-60%
   - 测量: 使用 HSL 分析工具,确保差异 ≤ 15%
3. **纸质纹理**: 角色与背景使用相同 paper_strength
   - 示例: 背景 0.20 → 角色 0.18-0.22
4. **边缘处理**: 角色与背景使用相同 edge_softness
   - 示例: 背景 0.03 → 角色 0.03

**情感效果**: 
- 宁静、归属感、"这是它的家"
- 玩家感到放松,不被打扰
- 适合长时间陪伴,无视觉疲劳

**Godot 实现示例**:
```gdscript
# 策略 A: 和谐融入模式
func set_character_harmony_mode():
    character_sprite.material.set_shader_parameter("saturation_boost", 0.1)  # +10% 饱和度
    character_sprite.material.set_shader_parameter("paper_strength", 0.20)   # 与背景一致
    character_sprite.material.set_shader_parameter("edge_softness", 0.03)    # 与背景一致
    character_sprite.modulate = Color(1.0, 1.0, 1.0, 1.0)  # 无额外调整
```

**使用频率**: 80% 的时间(日常陪伴为主)

#### 策略 B: 强调跳脱 (Emphasized Contrast)

**适用场景**: 
- 重要事件(角色有重要对话/决定/情绪爆发)
- 角色情绪激烈(非常开心/非常难过/惊讶/生气)
- 需要吸引玩家注意力的时刻
- 剧情关键节点

**视觉特征**: 
- 角色饱和度/对比度明显高于背景(差异 20-40%)
- 视觉焦点极其明确,角色立即吸引视线
- 可添加边缘光/辉光效果
- 背景相对降低饱和度,衬托角色

**实现方式**:
1. **色彩对比**: 角色使用强调色,与背景形成对比
   - 示例: 冷色背景 → 角色使用暖色强调色(橙/黄)
   - 示例: 暖色背景 → 角色使用冷色强调色(蓝/紫)
2. **饱和度提升**: 角色饱和度 = 背景饱和度 + 30%
   - 示例: 背景平均饱和度 50% → 角色 70-80%
   - 同时: 背景饱和度降低 10-20%,衬托角色
3. **对比度提升**: 角色对比度提高 30-50%
   - 实现: 使用 CanvasItemMaterial 的 modulate 或 Shader
4. **边缘光**: 添加轻微辉光或边缘高光
   - 实现: 使用 outline Shader 或 glow 效果
   - 强度: 轻微可见即可,不过度夸张

**情感效果**: 
- 戏剧性、紧张感、"发生了重要的事"
- 玩家注意力被吸引,感到"需要关注"
- 适合短时间使用,强调关键时刻

**Godot 实现示例**:
```gdscript
# 策略 B: 强调跳脱模式
func set_character_emphasis_mode():
    # 角色饱和度和对比度提升
    character_sprite.material.set_shader_parameter("saturation_boost", 0.3)  # +30% 饱和度
    character_sprite.material.set_shader_parameter("contrast_boost", 0.4)    # +40% 对比度
    character_sprite.material.set_shader_parameter("edge_glow", 0.15)        # 轻微边缘光
    character_sprite.modulate = Color(1.1, 1.1, 1.1, 1.0)  # 整体提亮 10%
    
    # 背景饱和度降低
    background_sprite.material.set_shader_parameter("saturation_boost", -0.15)  # -15% 饱和度
    background_sprite.modulate = Color(0.9, 0.9, 0.9, 1.0)  # 整体降低 10%
```

**使用频率**: 20% 的时间(关键时刻为主)

#### 策略切换动画

**平滑过渡**: 两种策略应通过动画平滑切换,避免突变

**A → B 过渡 (进入强调模式)**:
```gdscript
func transition_to_emphasis():
    var tween = create_tween()
    tween.set_parallel(true)
    
    # 角色参数渐变 (1 秒)
    tween.tween_method(
        func(v): character_sprite.material.set_shader_parameter("saturation_boost", v),
        0.1, 0.3, 1.0
    ).set_ease(Tween.EASE_OUT).set_trans(Tween.TRANS_CUBIC)
    
    tween.tween_method(
        func(v): character_sprite.material.set_shader_parameter("contrast_boost", v),
        0.0, 0.4, 1.0
    ).set_ease(Tween.EASE_OUT).set_trans(Tween.TRANS_CUBIC)
    
    tween.tween_method(
        func(v): character_sprite.material.set_shader_parameter("edge_glow", v),
        0.0, 0.15, 1.0
    ).set_ease(Tween.EASE_OUT).set_trans(Tween.TRANS_CUBIC)
    
    # 背景参数渐变 (1 秒)
    tween.tween_method(
        func(v): background_sprite.material.set_shader_parameter("saturation_boost", v),
        0.0, -0.15, 1.0
    ).set_ease(Tween.EASE_OUT).set_trans(Tween.TRANS_CUBIC)
```

**B → A 过渡 (退出强调模式)**:
```gdscript
func transition_to_harmony():
    var tween = create_tween()
    tween.set_parallel(true)
    
    # 角色参数渐变 (1.5 秒,比进入慢)
    tween.tween_method(
        func(v): character_sprite.material.set_shader_parameter("saturation_boost", v),
        0.3, 0.1, 1.5
    ).set_ease(Tween.EASE_IN).set_trans(Tween.TRANS_CUBIC)
    
    tween.tween_method(
        func(v): character_sprite.material.set_shader_parameter("contrast_boost", v),
        0.4, 0.0, 1.5
    ).set_ease(Tween.EASE_IN).set_trans(Tween.TRANS_CUBIC)
    
    tween.tween_method(
        func(v): character_sprite.material.set_shader_parameter("edge_glow", v),
        0.15, 0.0, 1.5
    ).set_ease(Tween.EASE_IN).set_trans(Tween.TRANS_CUBIC)
    
    # 背景参数渐变 (1.5 秒)
    tween.tween_method(
        func(v): background_sprite.material.set_shader_parameter("saturation_boost", v),
        -0.15, 0.0, 1.5
    ).set_ease(Tween.EASE_IN).set_trans(Tween.TRANS_CUBIC)
```

**过渡时机建议**:
- 对话开始 → 渐变到强调模式(1 秒)
- 对话结束 → 渐变回和谐模式(1.5 秒)
- 情绪变化 → 立即切换(0.5 秒快速过渡)
- 事件触发 → 立即切换到强调模式(0.3 秒)

#### 策略选择决策树

```
是否需要吸引玩家注意力?
├─ 是 → 使用策略 B (强调跳脱)
│   ├─ 重要对话/决定
│   ├─ 情绪激烈时刻
│   ├─ 剧情关键节点
│   └─ 需要玩家互动
└─ 否 → 使用策略 A (和谐融入)
    ├─ 日常陪伴
    ├─ 角色休息/睡觉
    ├─ 玩家工作时
    └─ 背景氛围营造
```

**注意事项**:
- 不要过度使用策略 B,否则失去"特殊"感
- 策略 B 持续时间建议 ≤ 2 分钟,之后回到策略 A
- 如果连续多个重要事件,可在事件间短暂回到策略 A,避免视觉疲劳
- 两种策略的 Shader 参数应通过配置文件管理,方便全局调整

### 角色提升路径详解

#### 维度 1: 辨识度

**Level 1 → Level 2: 强化轮廓对比**
- **操作**: 角色边缘与背景对比度提高到 3:1 以上
- **示例**: 使用 CanvasItemMaterial 的 outline 功能添加细微描边
- **技术**: 或在 Shader 中实现 edge detection + outline
- **验证**: 在复杂背景前角色轮廓应清晰可辨

**Level 2 → Level 3: 简化形状语言**
- **操作**: 将角色拆解为 3-5 个基础几何形状(圆/椭圆/三角)
- **示例**: 头部=大圆,身体=椭圆,四肢=小圆柱
- **技术**: 在 AI 提示词中强调 "simple geometric shapes, minimal complexity"
- **验证**: 用纯色剪影测试,应立即认出角色

**Level 3 → Polish: 放大关键特征**
- **操作**: 眼睛/耳朵/标志物尺寸放大 20-30%
- **示例**: 眼睛占头部面积 15-20%,耳朵/尾巴等特征明显
- **技术**: 在设计阶段调整比例,或在 Godot 中单独缩放关键部位
- **验证**: 缩小到 64px 时关键特征仍清晰

#### 维度 2: 表情表现力

**Level 1 → Level 2: 增加眼睛细节**
- **操作**: 眼睛添加高光点、瞳孔变化、眼睑动作
- **示例**: 开心=瞳孔放大+双高光,难过=瞳孔缩小+单高光
- **技术**: 使用独立 Sprite2D 节点控制眼睛,支持动态组合
- **验证**: 仅通过眼睛应能传达 5 种以上情绪

**Level 2 → Level 3: 嘴型变化丰富**
- **操作**: 准备 6-8 种嘴型(闭嘴/微笑/大笑/撅嘴/张嘴/咬牙等)
- **示例**: 每种情绪对应特定嘴型,避免重复使用
- **技术**: 嘴巴作为独立 Sprite2D,通过 AnimationPlayer 切换
- **验证**: 眼睛+嘴巴组合应能表达 20+ 种细微情绪

**Level 3 → Polish: 添加次级表情**
- **操作**: 耳朵/尾巴/触角等部位也参与表情表达
- **示例**: 开心=耳朵竖起+尾巴摇摆,难过=耳朵耷拉+尾巴下垂
- **技术**: 使用 Bone2D 或独立 Sprite2D + AnimationPlayer
- **验证**: 次级表情应增强主表情,不冲突

#### 维度 3: 动作流畅度

**Level 1 → Level 2: 增加中间帧**
- **操作**: 关键动作(挥手/跳跃)增加到 8-12 帧
- **示例**: idle 4 帧 → 6 帧,wave 6 帧 → 10 帧
- **技术**: 在 AI 生成时要求 "smooth animation, multiple in-between frames"
- **验证**: 播放速度 12fps 时动作应流畅无跳跃

**Level 2 → Level 3: 添加缓入缓出**
- **操作**: 动作开始和结束时速度变化,中间匀速
- **示例**: 挥手动作前 2 帧慢速启动,中间 6 帧匀速,最后 2 帧减速
- **技术**: 在 AnimationPlayer 中调整帧间隔,或使用 Tween
- **验证**: 动作应有节奏感,不是机械匀速

**Level 3 → Polish: 身体部件延迟跟随**
- **操作**: 头部先动,身体延迟 1-2 帧跟随,四肢再延迟 1-2 帧
- **示例**: 转身动作:头部先转 → 身体跟随 → 尾巴最后甩过来
- **技术**: 使用 Bone2D + IK 或分层 AnimationPlayer
- **验证**: 动作应有重量感和惯性,像真实生物

#### 维度 4: 风格一致性

**Level 1 → Level 2: 匹配边缘处理**
- **操作**: 角色使用与背景相同的边缘柔化强度
- **示例**: 背景 edge_softness = 0.03,角色也使用 0.03
- **技术**: 应用相同的 edge_softening.gdshader
- **验证**: 角色与背景边缘质感应一致

**Level 2 → Level 3: 统一纸质纹理强度**
- **操作**: 角色纸质纹理强度与背景接近(±5%)
- **示例**: 背景 paper_strength = 0.2,角色 = 0.18 ~ 0.22
- **技术**: 应用相同的 paper_overlay.gdshader,微调参数
- **验证**: 角色应有相同的手绘温暖感

**Level 3 → Polish: 调整色彩饱和度**
- **操作**: 角色饱和度略高于背景 10-15%,保持视觉焦点
- **示例**: 背景平均饱和度 50%,角色 60-65%
- **技术**: 在 AI 生成时控制,或在 Godot 中使用 modulate 调整
- **验证**: 角色应突出但不刺眼,与背景和谐共存

#### 维度 5: 性格传达

**Level 1 → Level 2: 调整体态**
- **操作**: 通过姿态传达性格(挺拔=自信,慵懒=随性,前倾=好奇)
- **示例**: 活泼角色 idle 姿态略微前倾,沉静角色略微后仰
- **技术**: 在 AI 提示词中描述姿态 "confident upright posture" 或 "relaxed slouching pose"
- **验证**: 静态姿态应暗示性格倾向

**Level 2 → Level 3: 动作速度差异**
- **操作**: 不同性格角色动作节奏不同
- **示例**: 活泼角色动画 12fps,沉静角色 8fps
- **技术**: 在 AnimatedSprite2D 中设置不同的 speed_scale
- **验证**: 动作节奏应与性格匹配,玩家能"感觉到"差异

**Level 3 → Polish: 细节装饰**
- **操作**: 添加符合性格的配饰/纹样/道具
- **示例**: 学者角色戴眼镜+拿书,冒险角色戴帽子+背包
- **技术**: 作为独立 Sprite2D 附加到角色,可选显示/隐藏
- **验证**: 装饰应强化性格认知,不喧宾夺主

#### 维度 6: 可爱度

**Level 1 → Level 2: 调整头身比**
- **操作**: 头身比控制在 1:1.5 ~ 1:2.5 之间,避免过度 Q 版
- **示例**: 头部高度占总高度 40-50%,不超过 60%
- **技术**: 在设计阶段控制比例
- **验证**: 角色应可爱但不幼稚,成年玩家能接受

**Level 2 → Level 3: 眼睛大小适中**
- **操作**: 眼睛占头部面积 15-20%,不超过 25%
- **示例**: 避免"大眼萌"风格,保持一定成熟度
- **技术**: 在 AI 提示词中明确 "moderately sized eyes, not overly large"
- **验证**: 眼睛应有表现力但不夸张

**Level 3 → Polish: 添加成熟元素**
- **操作**: 通过纹理/配饰/色彩增加成熟感
- **示例**: 使用低饱和度配色,添加细微纹理细节,避免纯色块
- **技术**: 在 AI 提示词中添加 "subtle texture details, muted color palette"
- **验证**: 角色应在"可爱"与"成熟"之间找到平衡

## 质量评估流程

### 首批素材评估(3-5 个样本)

**目标**: 验证标准是否可执行,调整矩阵参数

**步骤**:
1. **生成样本**: 按照 asset-creation-workflow.md 生成 3 个背景 + 2 个角色姿态
2. **内部评估**: 对照矩阵逐维度打分(1-5 分)
3. **用户测试**: 5-10 人盲测,收集关键词反馈("温暖"/"杂乱"/"可爱"/"幼稚"等)
4. **标准调整**: 
   - 如果某维度普遍达不到"最低可接受",降低标准或提供更具体的提升路径
   - 如果某维度普遍超过"理想目标",提高标准避免过度投入
5. **更新文档**: 在 quality-iteration-guide.md 中记录调整决策

### 批量生产评估(每 10 个素材)

**目标**: 保持一致性,及早发现偏差

**检查点**:
- [ ] 色彩是否仍在调色板范围内
- [ ] 纸质纹理强度是否一致
- [ ] 新素材与已有素材放在一起是否和谐
- [ ] 文件命名/格式/尺寸是否符合规范

**纠偏机制**:
- 发现 3 个以上素材偏离标准 → 暂停生产,回顾 workflow
- 发现某个 AI 工具输出质量下降 → 切换工具或调整提示词
- 发现某类素材(如夜景)普遍质量低 → 为该类别创建专门提示词模板

## 快速参考: 质量检查清单

### 背景场景检查清单 (详细版)

#### 第一层: 快速筛查 (30 秒)
- [ ] **氛围感知**: 瞥一眼能说出 1-2 个情绪关键词(温暖/宁静/神秘/活泼)
- [ ] **层次可辨**: 前中后景在视觉上可区分,不混成一团
- [ ] **色彩合规**: 所有颜色在调色板范围内,无明显冲突或刺眼颜色
- [ ] **纸质纹理**: 100% 缩放下可见纹理,但不抢夺注意力
- [ ] **边缘质感**: 边缘柔和自然,无生硬矢量感或锯齿
- [ ] **信息清晰**: 关键元素(门/窗/家具)3 秒内可辨识

**判断标准**: 6 项全部通过 → 进入第二层检查; 任意 1 项不通过 → 返工

#### 第二层: 量化验证 (2 分钟)

**氛围营造 (目标: ≥3 分)**
- [ ] 有明确光源方向(窗户/灯具/天光)
- [ ] 光源产生可见阴影或光斑
- [ ] 色调与情绪基调匹配(暖色=温暖,冷色=宁静)
- [ ] 对比度比 ≥ 2:1 (最亮区域 vs 最暗区域)
- [ ] 5 秒测试: 3 人中至少 2 人能说出正确的场景类型和时间段

**层次分离 (目标: ≥3 分)**
- [ ] 灰度模式下三层有明显亮度差异(测量 RGB 平均值差异 ≥ 30)
- [ ] 远景对比度比中景低 ≥ 15%
- [ ] 近景对比度比中景高 ≥ 15%
- [ ] 高斯模糊 5px 后层次边界仍可辨识
- [ ] 如有视差: 三层移动速度比明显(建议 1:2:4)

**色彩和谐 (目标: ≥3 分)**
- [ ] 色相范围 ≤ 120° (在色轮上集中分布)
- [ ] 饱和度范围 ≤ 40% (避免极端饱和或灰暗)
- [ ] 色温统一 ±300K (暖色场景无突兀冷色,反之亦然)
- [ ] 主色占比 50-70%,辅助色 20-40%,强调色 5-15%
- [ ] 5 分钟长时间观看无视觉疲劳或不适

**纸质感 (目标: ≥3 分)**
- [ ] 纹理强度 15-25% (paper_strength = 0.15 ~ 0.25)
- [ ] 纹理颗粒大小适中(不过大像素化,不过小噪点化)
- [ ] 100% 缩放下纹理可见,50% 缩放下融入画面
- [ ] 关闭纹理 vs 开启纹理有明显温暖感差异
- [ ] 与其他素材纹理强度视觉一致

**边缘处理 (目标: ≥3 分)**
- [ ] 边缘羽化半径 2-5px (edge_softness = 0.02 ~ 0.05)
- [ ] Alpha 渐变平滑,无突变或锯齿
- [ ] 放大到 200% 观察,边缘柔和自然
- [ ] 在不同背景前显示,无明显"抠图感"
- [ ] 边缘有轻微不规则变化(非均匀模糊)

**信息清晰度 (目标: ≥3 分)**
- [ ] 关键元素对比度 ≥ 3:1 (与背景对比)
- [ ] 关键元素边缘清晰度 ≥ 80%
- [ ] 3 秒快速识别测试: 正确率 ≥ 80%
- [ ] 功能区域明确(玩家能指出角色活动区域)
- [ ] 次要细节不干扰关键信息(装饰性元素对比度低)

**判断标准**: 
- 所有维度 ≥3 分 → 通过,可用于生产
- 任意维度 <3 分 → 需改进,参考提升路径
- 任意维度 =1 分 → 严重问题,必须返工

#### 第三层: 场景类型特殊检查 (1 分钟)

**室内场景额外检查**
- [ ] 有明确光源(窗户/灯具),光影逻辑合理
- [ ] 透视正确,不过度夸张也不过于扁平
- [ ] 有适量道具暗示居住者性格,但不杂乱(道具数量 3-8 个)
- [ ] 墙面/地板/天花板比例合理(建议 3:4:1)
- [ ] 家具尺寸符合人体工学(椅子高度约为房间高度的 1/4)

**室外场景额外检查**
- [ ] 天空占比 30-50%,渐变自然
- [ ] 天空色调支撑时间段氛围(清晨=粉橙,正午=蓝白,黄昏=橙红,夜晚=深蓝)
- [ ] 远景明显模糊且低饱和(饱和度比近景低 30-50%)
- [ ] 植物/云朵等自然元素边缘柔和有机
- [ ] 地平线位置合理(建议在画面下 1/3 或上 1/3 处)

**特殊场景额外检查**
- [ ] 色彩偏移明确但仍和谐(可偏离标准调色板 ±30°)
- [ ] 抽象化程度适中(简化细节但保持可辨识)
- [ ] 与常规场景有明显视觉区分(色调/纹理/边缘至少 2 项不同)
- [ ] 过渡标记清晰(玩家能立即意识到"这是特殊场景")
- [ ] 特殊效果不破坏整体风格(仍符合水彩手绘语言)

### 角色检查清单 (详细版)

#### 第一层: 快速筛查 (30 秒)
- [ ] **辨识度**: 缩小到 64px 仍可辨识,轮廓独特
- [ ] **表情清晰**: 当前表情能清晰传达情绪,无歧义
- [ ] **动作流畅**: 播放动画无跳跃感,过渡自然
- [ ] **风格统一**: 边缘/纹理/色彩与背景风格一致
- [ ] **性格暗示**: 外形/姿态/配色暗示性格倾向
- [ ] **可爱度**: 讨喜不幼稚,成年玩家能接受

**判断标准**: 6 项全部通过 → 进入第二层检查; 任意 1 项不通过 → 返工

#### 第二层: 量化验证 (2 分钟)

**辨识度 (目标: ≥3 分)**
- [ ] 64px 缩放测试: 5 人中至少 4 人能认出角色
- [ ] 轮廓对比度 ≥ 3:1 (与背景对比)
- [ ] 关键特征(眼睛/耳朵/标志物)占比合理(眼睛占头部 15-20%)
- [ ] 纯色剪影测试: 能立即认出角色
- [ ] 与其他角色并排显示,轮廓明显不同

**表情表现力 (目标: ≥3 分)**
- [ ] 基础情绪(开心/难过/惊讶/生气/害怕)可通过眼睛+嘴巴传达
- [ ] 眼睛有细节(高光/瞳孔/眼睑),不是简单黑点
- [ ] 嘴型变化丰富(至少 6 种: 闭嘴/微笑/大笑/撅嘴/张嘴/咬牙)
- [ ] 表情测试: 5 人中至少 4 人能正确识别情绪
- [ ] 微妙情绪(好奇/思考/无奈)也能传达(4-5 分目标)

**动作流畅度 (目标: ≥3 分)**
- [ ] 关键动作帧数 ≥ 6 帧 (idle 4-6 帧,复杂动作 8-12 帧)
- [ ] 播放速度 12fps 时无跳跃感
- [ ] 关键帧之间过渡自然,无突变
- [ ] 动作有节奏感(非机械匀速)
- [ ] 身体部件协调(头/身体/四肢同步或有合理延迟)

**风格一致性 (目标: ≥3 分)**
- [ ] 边缘柔化强度与背景一致(±0.01)
- [ ] 纸质纹理强度与背景接近(±5%)
- [ ] 色彩饱和度略高于背景 10-15%,但不刺眼
- [ ] 放在背景上视觉和谐,无违和感
- [ ] 与其他角色风格一致(边缘/纹理/色彩处理相同)

**性格传达 (目标: ≥3 分)**
- [ ] 外形暗示性格(圆润=温和,尖锐=锐利,方正=稳重)
- [ ] 配色暗示性格(暖色=活泼,冷色=沉静,中性=平和)
- [ ] 姿态暗示性格(挺拔=自信,慵懒=随性,前倾=好奇)
- [ ] 动作节奏匹配性格(活泼=快速,沉静=缓慢)
- [ ] 性格测试: 5 人中至少 3 人能说出相似的性格关键词

**可爱度 (目标: ≥3 分)**
- [ ] 头身比 1:1.5 ~ 1:2.5 (不过度 Q 版)
- [ ] 眼睛占头部面积 15-20% (不超过 25%)
- [ ] 有成熟元素(纹理细节/配饰/低饱和配色)
- [ ] 成年玩家接受度测试: 10 人中至少 7 人评价"可爱但不幼稚"
- [ ] 避免过度萌化特征(过大眼睛/过小嘴巴/过短四肢)

**判断标准**: 
- 所有维度 ≥3 分 → 通过,可用于生产
- 任意维度 <3 分 → 需改进,参考提升路径
- 任意维度 =1 分 → 严重问题,必须返工

#### 第三层: 动画完整性检查 (1 分钟)

**必需动画集**
- [ ] idle (待机): 4-6 帧,循环流畅,有呼吸感
- [ ] happy (开心): 6-8 帧,表情+动作配合
- [ ] sad (难过): 6-8 帧,表情+姿态配合
- [ ] surprised (惊讶): 4-6 帧,瞬间反应感
- [ ] thinking (思考): 6-8 帧,有延迟感和节奏

**可选动画集 (根据角色需求)**
- [ ] wave (挥手): 8-10 帧,手臂运动流畅
- [ ] sleep (睡觉): 4-6 帧,呼吸起伏明显
- [ ] eat (吃东西): 8-12 帧,嘴巴+手部协调
- [ ] read (阅读): 4-6 帧,眼睛移动+翻页动作

**动画过渡检查**
- [ ] idle → happy 过渡自然(无跳跃)
- [ ] happy → sad 过渡自然(有情绪转换过程)
- [ ] 任意动画 → idle 过渡自然(回到中性状态)
- [ ] 循环动画首尾帧衔接完美(无闪烁或跳跃)

### 整体和谐度检查清单 (详细版)

#### 角色-背景组合检查 (2 分钟)
- [ ] **视觉舒适度**: 角色放在背景上长时间观看(5 分钟)无不适
- [ ] **色彩关系**: 角色与背景色彩互补或和谐,无冲突
- [ ] **对比度**: 角色比背景突出,但不过度刺眼(饱和度差 10-20%)
- [ ] **边缘融合**: 角色边缘与背景自然融合,无"抠图感"
- [ ] **光影一致**: 角色光源方向与背景一致(如背景左侧光源,角色也左侧受光)
- [ ] **纸质纹理**: 角色与背景纹理强度视觉一致(±5%)
- [ ] **情绪匹配**: 角色情绪与背景氛围匹配(如温暖背景+开心角色)

#### 视觉层级检查 (1 分钟)
- [ ] **焦点顺序**: 玩家视线顺序应为 角色 > UI > 背景
- [ ] **对比度层级**: 角色对比度 > UI 对比度 > 背景对比度
- [ ] **饱和度层级**: 角色饱和度 > UI 饱和度 > 背景饱和度
- [ ] **细节密度层级**: 角色细节最丰富,背景细节最简化
- [ ] **视线追踪测试**: 90% 测试者首先看向角色

#### 风格一致性检查 (2 分钟)
- [ ] **与已有素材对比**: 新素材与已有素材并排显示,风格统一
- [ ] **边缘处理一致**: 所有素材边缘柔化强度视觉一致
- [ ] **纸质纹理一致**: 所有素材纹理强度和颗粒大小视觉一致
- [ ] **色彩语言一致**: 所有素材使用相同调色板,色温统一
- [ ] **几何简化一致**: 所有素材简化程度相似(不混杂写实和抽象)

#### 设计柱对齐检查 (1 分钟)
- [ ] **陪伴不打扰**: 背景不抢夺注意力,角色存在感适中
- [ ] **温暖治愈**: 整体色调温暖,氛围宁静,无压迫感
- [ ] **窥视碎片**: 边缘有水彩晕染感,符合"透过窗口看世界"的设定
- [ ] **情感共鸣**: 场景+角色组合能引发情感反应(温暖/宁静/好奇等)
- [ ] **长期陪伴**: 长时间观看(30 分钟)无视觉疲劳,仍感舒适

### 批量生产检查清单 (每 10 个素材)

#### 一致性检查
- [ ] **色彩范围**: 所有素材颜色在调色板内,无偏离
- [ ] **纸质纹理**: 纹理强度标准差 ≤ 0.05 (目标 0.15-0.25)
- [ ] **边缘处理**: 边缘柔化强度标准差 ≤ 0.01 (目标 0.02-0.05)
- [ ] **文件规范**: 命名/格式/尺寸符合规范,无例外

#### 质量趋势检查
- [ ] **质量稳定**: 最近 10 个素材平均分 ≥ 3.0,无下降趋势
- [ ] **返工率**: 返工率 ≤ 30%,如超过需检查 workflow
- [ ] **特定问题**: 无重复出现的特定问题(如夜景普遍质量低)

#### 工具性能检查
- [ ] **AI 输出稳定**: 同一提示词多次生成结果一致性 ≥ 70%
- [ ] **提示词有效**: 提示词能稳定产出目标质量,无需大量重试
- [ ] **后期处理**: Shader 参数稳定,无需频繁调整

**纠偏触发条件**:
- 3 个以上素材偏离标准 → 暂停生产,回顾 workflow
- 返工率 > 50% → 检查提示词或切换 AI 工具
- 某类素材(如夜景)普遍质量低 → 创建专门提示词模板
