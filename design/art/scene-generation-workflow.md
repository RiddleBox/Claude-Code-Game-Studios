# Scene Generation Workflow

*Created: 2026-04-24*
*Status: Draft*
*Purpose: 定义从场景内容设计到最终美术资产的完整工作流*

---

## Overview

本工作流将场景主题设计（内容）与视觉风格指南（表现）结合，生成可直接用于游戏引擎的美术资产。

```
场景内容设计 + 视觉风格 → AI提示词 → 美术资产 → 引擎集成
```

---

## Workflow Stages

### Stage 1: Content Design（内容设计）

**输入**：游戏设计需求（GDD）

**工具**：`scene-theme-library/theme-template.md`

**产出**：完整的场景主题文档

**步骤**：
1. 复制 `theme-template.md`，重命名为 `theme-XX-descriptive-name.md`
2. 填写5个维度：
   - Dimension 1: 世界观定位
   - Dimension 2: 场景地理位置
   - Dimension 3: 场景功能类型
   - Dimension 4: 场景叙事状态
   - Dimension 5: 角色性格体现
3. 设计分层构图（前景/中景/远景）
4. 完成元素检查清单
5. 定义色彩方案
6. 获得审批

**验收标准**：
- [ ] 5个维度全部填写完整
- [ ] 前/中/远景物品清单明确
- [ ] 必须元素检查清单全部通过
- [ ] 色彩方案已定义

**时间估算**：1-2小时（首次设计），30分钟（后续主题）

---

### Stage 2: Style Application（风格应用）

**输入**：场景主题文档 + `visual-style-guide.md`

**工具**：`visual-style-guide.md`、`art-bible.md`

**产出**：风格决策文档（可以是主题文档的一部分）

**步骤**：
1. 从 `visual-style-guide.md` 选择绘画风格
   - 线稿+水彩
   - 油画
   - 像素艺术
   - 其他
2. 确定细节密度策略
   - 前景：50-70%
   - 中景：30-50%
   - 远景：10-30%
3. 确定色彩处理方式
   - 全彩
   - 选择性上色
   - 黑白+局部色
4. 确定笔触质感
   - 速写感
   - 精细渲染
   - 平涂

**验收标准**：
- [ ] 绘画风格已选择
- [ ] 细节密度策略已确定
- [ ] 色彩处理方式已确定
- [ ] 笔触质感已确定

**时间估算**：15-30分钟

---

### Stage 3: Prompt Engineering（提示词工程）

**输入**：场景主题文档 + 风格决策

**工具**：本文档的提示词模板

**产出**：AI生成提示词（正向+负向）

**步骤**：
1. 提取内容描述（从主题文档）
2. 提取风格描述（从风格决策）
3. 组合为分层提示词：
   - 前景描述（高细节）
   - 中景描述（中细节）
   - 远景描述（低细节）
4. 添加技术参数（分辨率、构图、视角）
5. 编写负向提示词（排除不需要的元素）
6. 针对目标工具优化（Midjourney/Nana Banana/Stable Diffusion）

**提示词结构模板**：

```
[风格声明], [视角声明], [前景内容], [中景内容], [远景内容], [光照], [色彩方案], [技术参数]

负向: [排除元素], [排除风格], [排除构图]
```

**验收标准**：
- [ ] 提示词包含前/中/远景描述
- [ ] 提示词包含风格和技术参数
- [ ] 负向提示词已编写
- [ ] 已针对目标工具优化

**时间估算**：30-45分钟

---

### Stage 4: Generation & Iteration（生成与迭代）

**输入**：AI提示词

**工具**：AI图像生成工具（Midjourney/Nana Banana/Stable Diffusion）

**产出**：候选美术资产（多个版本）

**步骤**：
1. **首次生成**（3-5张）
   - 使用完整提示词生成
   - 评估整体构图和氛围
2. **质量评分**（使用 `quality-iteration-guide.md` 的7维度评分）
   - Dimension 1: 世界观辨识度
   - Dimension 2: 空间可读性
   - Dimension 3: 角色活动区清晰度
   - Dimension 4: 生活感/使用痕迹
   - Dimension 5: 色彩层次
   - Dimension 6: 光照合理性
   - Dimension 7: 细节密度对比（前景 vs 背景）
3. **迭代调整**（如需要）
   - 调整提示词中的问题部分
   - 重新生成
   - 再次评分
4. **选择最佳版本**
   - 所有维度 ≥3/5
   - 符合主题文档的设计意图

**验收标准**：
- [ ] 至少1张候选资产所有维度 ≥3/5
- [ ] 构图符合分层设计（前/中/远景清晰）
- [ ] 色彩方案符合定义
- [ ] 角色活动区清晰可辨

**时间估算**：1-3小时（取决于迭代次数）

**迭代上限**：
- 简单场景：最多3轮迭代
- 中等场景：最多5轮迭代
- 复杂场景：最多8轮迭代
- 如超过上限仍未达标 → 升级到 `layered-generation-workflow.md`（分层生成）

---

### Stage 5: Post-Processing（后期处理）

**输入**：选定的候选资产

**工具**：Photoshop/Krita/GIMP

**产出**：最终美术资产（可直接用于引擎）

**步骤**：
1. **尺寸调整**
   - 原始生成：1920×1080（或更高）
   - 保留高分辨率版本（用于后期调整）
   - 导出引擎用版本：320×320（如需）
2. **色彩校正**（如需要）
   - 调整整体色温
   - 调整饱和度
   - 调整对比度
3. **细节优化**（如需要）
   - 修复AI生成的瑕疵
   - 增强前景细节
   - 简化背景（如过于复杂）
4. **纹理叠加**（如需要）
   - 添加纸张纹理
   - 添加噪点（增强手绘感）
5. **导出**
   - 格式：PNG
   - 透明背景：根据需要
   - 文件大小：<2MB
   - 命名：`bg_[theme-id]_[state].png`

**验收标准**：
- [ ] 文件格式正确（PNG）
- [ ] 文件大小 <2MB
- [ ] 命名规范正确
- [ ] 在320×320分辨率下仍可辨识关键元素

**时间估算**：30-60分钟

---

### Stage 6: Engine Integration（引擎集成）

**输入**：最终美术资产

**工具**：Godot 4.6.1

**产出**：可在游戏中使用的场景背景

**步骤**：
1. **导入资产**
   - 复制文件到 `assets/art/backgrounds/`
   - Godot自动导入，生成 `.import` 文件
2. **创建场景资源**
   - 在P1主界面UI中引用
   - 设置为Layer 2背景层
3. **测试功能**
   - 测试正常显示
   - 测试外出态变暗（modulate至20%亮度）
   - 测试泄漏内容叠加（文字是否可读）
4. **验证分辨率**
   - 在320×320窗口中查看效果
   - 确认关键元素可辨识
5. **性能测试**
   - 检查加载时间
   - 检查内存占用

**验收标准**：
- [ ] 资产成功导入Godot
- [ ] 在P1中正常显示
- [ ] 外出态变暗效果正常
- [ ] 泄漏内容叠加不影响可读性
- [ ] 320×320分辨率下效果可接受

**时间估算**：15-30分钟

## Prompt Engineering Templates（提示词模板）

### Template 1: 线稿+水彩风格（当前推荐）

**适用场景**：温馨、治愈、手绘感强的场景

**正向提示词结构**：
```
建筑师手绘速写风格，钢笔线条加淡水彩渲染，[场景类型]，[前景物品列表]，[中景家具和墙面]，[远景窗外景色]，[光照描述]，[色彩方案]，前景密集线条细节，中景适度细节，远景简化轮廓，选择性上色策略，16:9横向构图

关键强化：
- 淡水彩渲染（light watercolor wash）
- 前景极密集线条（extremely dense linework in foreground）
- 远景极简轮廓（minimal outline for background）
- 选择性上色（selective coloring）
```

**负向提示词**：
```
纯白纸张底色，平涂颜色无渐变，色彩严格在线稿内不溢出，饱和度过高，鲜艳颜色，漫画风格，完成的插画，工整，可爱风格，对称构图，现实世界场景，玩家的房间，办公室，现代工作室
```

**示例**（魔导工坊场景）：
```
建筑师手绘速写风格，钢笔线条加淡水彩渲染，魔导工匠的工作室内景，前景工作台上有半组装的魔导装置、散落的工具、冒热气的茶杯、翻开的设计图纸，中景木质L型工作台、工具架、高脚凳、墙面挂钟，远景窗外魔导朋克城市广场、钟楼轮廓、淡蓝天空，午后阳光从左侧窗户照入，暖木色前景、米黄墙面、淡蓝远景，前景密集交叉排线和木纹，中景适度细节，远景简化建筑轮廓，窗外天空蓝白渐变，木质元素暖橙色，其他部分淡米黄，16:9横向构图

负向：纯白底色，平涂，鲜艳颜色，漫画风格，完成插画，对称构图，现代办公室，玩家房间
```

### Template 2: 分层生成策略（复杂场景）

**适用场景**：单次生成难以达标的复杂场景

**参考文档**：`layered-generation-workflow.md`

**三阶段生成**：
1. **Pass 1: 色块基础层**
   - 只生成色彩分布和大致构图
   - 无细节，无线稿
2. **Pass 2: 选择性细节添加**
   - 手动或AI img2img添加前景细节
   - 保持背景简化
3. **Pass 3: 最终润色**
   - 纹理叠加
   - 色彩调整
   - 导出

**时间成本**：比单次生成多30-60分钟

**使用条件**：
- 单次生成3轮迭代后仍未达标
- 场景复杂度高（前景物品 >10个）
- 需要精确控制细节分布

## Quality Scoring System（质量评分系统）

使用 `quality-iteration-guide.md` 的7维度评分，但针对场景背景调整：

### Dimension 1: 世界观辨识度（World Identity）

**评分标准**：
- 5分：一眼就能看出是异世界，世界观特征明显（魔法元素/奇幻建筑/独特科技）
- 4分：有明确的异世界元素，但不够突出
- 3分：有暗示性元素，需要仔细看才能发现
- 2分：几乎看不出异世界特征，像现实世界
- 1分：完全是现实世界场景

**目标**：≥3分（MVP），≥4分（完整版）

---

### Dimension 2: 空间可读性（Space Clarity）

**评分标准**：
- 5分：空间类型一目了然（工作室/卧室/店铺），家具布局清晰
- 4分：空间类型可辨识，但布局略显混乱
- 3分：能看出是室内，但具体类型不明确
- 2分：空间混乱，难以理解布局
- 1分：完全无法辨识空间类型

**目标**：≥4分

---

### Dimension 3: 角色活动区清晰度（Character Space）

**评分标准**：
- 5分：前景有明确的角色站立/坐的位置，空间充足
- 4分：有角色活动区，但略显拥挤
- 3分：勉强能放置角色，但空间紧张
- 2分：前景过于拥挤，难以放置角色
- 1分：完全没有角色活动空间

**目标**：≥4分

---

### Dimension 4: 生活感/使用痕迹（Living Traces）

**评分标准**：
- 5分：有3个以上明显的"被使用过"细节（翻开的书/半空的杯子/散落的工具）
- 4分：有2个使用痕迹
- 3分：有1个使用痕迹
- 2分：场景过于整洁，像样板间
- 1分：完全无生活感

**目标**：≥3分

---

### Dimension 5: 色彩层次（Color Hierarchy）

**评分标准**：
- 5分：前景/中景/远景色彩层次分明，饱和度递减明显
- 4分：有色彩层次，但对比不够强
- 3分：有轻微层次，但不明显
- 2分：色彩均匀分布，无层次
- 1分：色彩混乱，无规划

**目标**：≥4分

---

### Dimension 6: 光照合理性（Lighting Logic）

**评分标准**：
- 5分：光源明确，阴影方向一致，光照自然
- 4分：光源明确，但阴影略显不自然
- 3分：有光照感，但光源不明确
- 2分：光照混乱，多个矛盾光源
- 1分：完全无光照逻辑

**目标**：≥3分

---

### Dimension 7: 细节密度对比（Detail Contrast）

**评分标准**：
- 5分：前景细节密度明显高于背景（50-70% vs 10-30%），对比强烈
- 4分：有细节对比，但差异不够大
- 3分：有轻微对比，前景略多细节
- 2分：细节密度均匀，无对比
- 1分：背景细节反而比前景多（违反设计）

**目标**：≥4分

## Decision Tree（决策树）

```
开始场景设计
    ↓
填写主题模板（Stage 1）
    ↓
选择视觉风格（Stage 2）
    ↓
生成提示词（Stage 3）
    ↓
首次生成（3-5张）
    ↓
质量评分 → 所有维度 ≥3？
    ├─ 是 → 进入后期处理（Stage 5）
    └─ 否 → 迭代次数 <3？
            ├─ 是 → 调整提示词，重新生成
            └─ 否 → 切换到分层生成工作流
                    ↓
                分层生成 → 质量评分 → ≥3？
                    ├─ 是 → 进入后期处理
                    └─ 否 → 升级到 creative-director（重新设计）
```

## Tool-Specific Tips（工具特定技巧）

### Nana Banana

**优势**：
- 中文提示词支持好
- 适合温馨、治愈风格
- 生成速度快

**劣势**：
- 对"未完成速写感"理解有限
- 细节密度对比难以精确控制

**优化建议**：
- 使用中文提示词
- 强调"前景密集细节，背景简化"
- 多生成几张选最佳

---

### Midjourney v6

**优势**：
- 对建筑速写风格理解好
- 细节密度控制精确
- 支持风格参考

**劣势**：
- 需要英文提示词
- 生成成本较高

**优化建议**：
- 使用 `--style raw --stylize 300-400`
- 使用 `--ar 16:9`
- 如需更多细节对比，加 `--chaos 20`

---

### Stable Diffusion

**优势**：
- 完全可控
- 支持ControlNet（精确控制构图）
- 可使用LoRA模型

**劣势**：
- 需要技术知识
- 调参复杂

**优化建议**：
- 使用 "architectural sketch" LoRA
- 使用 ControlNet Lineart 控制线稿密度
- 分层生成（线稿层+色彩层）
