## 什么是故事碎片

### 定义

故事碎片是《窗语》中的核心叙事单元。它是角色在外出归来时带回的**记忆片段**，通过简短的文字向玩家透露角色的内心世界、过去经历、或当下感受。

### 核心特征

1. **简短**: 50-200字，一次阅读不超过30秒
2. **独立**: 每个碎片可以单独理解，不依赖完整故事线
3. **克制**: 不直接解释，留有想象空间
4. **渐进**: 通过多个碎片逐步揭示完整故事

### 在游戏中的作用

- **叙事载体**: 主要的故事讲述方式
- **情感连接**: 让玩家理解和共鸣角色
- **进度奖励**: 陪伴时间越长，解锁越多碎片
- **好奇驱动**: 激发玩家继续陪伴的动力

## 设计原则

### 1. 窥视感 (Voyeuristic Perspective)

**原则**: 玩家是**观察者**，不是**参与者**

✅ **正确示例**:
```
她翻开日记本，停在某一页很久。
最后还是合上了，什么也没写。
```

❌ **错误示例**:
```
她看着你，想要告诉你一些事情。
但她犹豫了，最终还是没有说出口。
```

**为什么**: 错误示例中"看着你"打破了观察关系，玩家不应该被角色直接感知。

---

### 2. 真实存在感 (Authentic Presence)

**原则**: 角色有自己的生活，碎片是她真实经历的记录

✅ **正确示例**:
```
今天遇到了一只流浪猫。
它蹭了蹭她的腿，然后跑开了。
她想，下次带点吃的吧。
```

❌ **错误示例**:
```
为了让你开心，她今天特意去了公园。
她希望你会喜欢这个故事。
```

**为什么**: 错误示例中角色的行为是"为了玩家"，而不是自己的真实生活。

---

### 3. 不完整叙事 (Incomplete Narrative)

**原则**: 不要解释一切，留白比填满更有力量

✅ **正确示例**:
```
抽屉里还放着那封信。
她每次路过都会看一眼，但从未打开。
已经三年了。
```

❌ **错误示例**:
```
抽屉里放着前男友的信。
她不敢打开是因为害怕回忆起分手的痛苦。
她需要时间来治愈这段感情。
```

**为什么**: 错误示例过度解释，剥夺了玩家的想象空间和解读乐趣。

---

### 4. 陪伴不打扰 (Companionship Without Intrusion)

**原则**: 碎片是**发现**，不是**推送**

✅ **正确示例**:
```
她在窗边站了很久。
外面开始下雨了。
她没有关窗。
```

❌ **错误示例**:
```
【重要提示】她现在心情不好！
快来安慰她吧！
```

**为什么**: 错误示例强制要求玩家关注和行动，违反了"不打扰"原则。

---

### 5. 性格即命运 (Character Drives Narrative)

**原则**: 碎片内容应该反映角色的性格特质

**示例**: 如果角色性格是"内向但好奇"

✅ **符合性格**:
```
书店新到了一本关于深海生物的书。
她翻了很久，最后还是买下了。
虽然可能永远不会去海边。
```

❌ **不符合性格**:
```
她在派对上认识了很多新朋友。
大家都很喜欢她的幽默感。
她觉得今天真是太棒了！
```

**为什么**: 第二个示例更适合外向性格，与"内向但好奇"的设定冲突。

## 碎片类型详解

### Scene (场景碎片)

**定义**: 描述角色经历的具体场景或事件

**特点**:
- 有明确的时间和地点
- 包含具体的行动和细节
- 通常是外部事件

**适用场景**:
- 日常生活片段
- 特殊事件记录
- 环境氛围营造

**示例**:
```
咖啡店的角落，她坐了一下午。
窗外的树叶从绿变黄，又从黄变红。
她点的咖啡早就凉了。
```

---

### Dialogue (对话碎片)

**定义**: 角色与他人的对话片段

**特点**:
- 包含直接引语
- 揭示人际关系
- 通过对话推进叙事

**适用场景**:
- 揭示角色关系
- 展现角色性格
- 推进故事线

**示例**:
```
"你最近还好吗？"邻居问。
"嗯，还好。"她回答。
其实她也不知道自己好不好。
```

---

### Object (物品碎片)

**定义**: 围绕特定物品展开的记忆或思考

**特点**:
- 物品是叙事核心
- 物品承载情感或记忆
- 通过物品连接过去和现在

**适用场景**:
- 揭示过去经历
- 营造怀旧氛围
- 建立情感锚点

**示例**:
```
旧书签还夹在那本书里。
上面的字迹已经模糊了。
她记得那是谁送的，但不记得是什么时候了。
```

---

### Emotion (情感碎片)

**定义**: 直接描述角色的内心感受和思考

**特点**:
- 更主观和内省
- 较少外部事件
- 情感权重通常较高

**适用场景**:
- 关键情感转折
- 深度角色刻画
- 建立情感共鸣

**示例**:
```
有时候她会想，如果当初选择了另一条路会怎样。
但这种想法总是很快就消失了。
因为没有答案。
```

## 写作指南

### 文字风格

**1. 使用第三人称**
- ✅ "她走进房间"
- ❌ "我走进房间"
- ❌ "你走进房间"

**2. 保持克制**
- ✅ "她的手在颤抖"
- ❌ "她非常非常害怕，手抖得厉害"

**3. 用细节代替形容词**
- ✅ "茶杯里的水已经凉了，表面浮着一层薄薄的茶渍"
- ❌ "茶很难喝"

**4. 短句为主**
- ✅ "雨停了。她打开窗。空气很清新。"
- ❌ "雨停了之后她打开了窗户，发现外面的空气非常清新。"

---

### 字数控制

| 碎片类型 | 推荐字数 | 最少 | 最多 |
|---------|---------|------|------|
| Scene | 80-150字 | 50字 | 200字 |
| Dialogue | 60-120字 | 50字 | 180字 |
| Object | 70-130字 | 50字 | 200字 |
| Emotion | 60-100字 | 50字 | 150字 |

**为什么有字数限制**:
- 太短: 缺乏足够信息，难以产生情感共鸣
- 太长: 打破"碎片"感，变成完整叙事，失去留白空间

---

### 时态使用

**推荐**: 一般过去时

✅ **正确**:
```
她走到窗边，看了看外面。
天色已经暗了。
```

❌ **不推荐**:
```
她正在走向窗边，正在看外面。
天色正在变暗。
```

**为什么**: 过去时强化"记忆片段"的感觉，现在进行时会让玩家觉得是实时发生的事件。

---

### 视角一致性

**规则**: 整个碎片保持同一视角

✅ **正确**:
```
她坐在书桌前。
笔记本上写了几行字，又划掉了。
她叹了口气。
```

❌ **错误**:
```
她坐在书桌前。
你能看到她很疲惫。
她叹了口气，希望你能理解她。
```

**为什么**: 视角跳跃会打破沉浸感。

---

## 解锁条件设计

### 亲密度阶梯

| 亲密度范围 | 阶段 | 适合的碎片内容 |
|-----------|------|---------------|
| 0-20 | 初识 | 日常琐事、表面观察、环境描述 |
| 21-40 | 熟悉 | 兴趣爱好、生活习惯、轻度情感 |
| 41-60 | 信任 | 过去经历、人际关系、中度情感 |
| 61-80 | 亲密 | 内心想法、脆弱时刻、深度情感 |
| 81-100 | 深度共鸣 | 核心秘密、转折时刻、强烈情感 |

**设计建议**:
- 早期碎片应该"安全"，不涉及敏感话题
- 随着亲密度提升，逐步揭示更私密的内容
- 最深层的碎片应该让玩家感到"被信任"

---

### 前置碎片链

**线性链**: A → B → C → D

**示例**:
```
fragment_cat_001: 遇到流浪猫
  ↓
fragment_cat_002: 开始喂养流浪猫
  ↓
fragment_cat_003: 给猫取名字
  ↓
fragment_cat_004: 猫不见了
```

**分支链**: A → B1 / B2 → C

**示例**:
```
fragment_letter_001: 收到一封信
  ↓
fragment_letter_002a: 打开了信（情感权重高）
fragment_letter_002b: 没有打开信（情感权重低）
  ↓
fragment_letter_003: 后续发展
```

**设计建议**:
- 不要让链条过长（最多5个碎片）
- 确保每个碎片即使单独看也有意义
- 分支应该有明确的差异和后果

---

### 时间条件

**使用场景**:
- 特定时间段的氛围（如深夜的孤独感）
- 与现实时间同步的体验（如早晨的清新感）
- 强化某些碎片的情感冲击

**示例**:
```json
{
  "time_range": {
    "start_hour": 22,
    "end_hour": 2
  }
}
```

**对应碎片**:
```
深夜两点，她还醒着。
窗外很安静，只有偶尔的车声。
她想，明天又要很累了。
```

**设计建议**:
- 不要过度使用时间限制（会降低碎片触发率）
- 时间范围应该足够宽（至少3-4小时）
- 确保时间与内容有强关联

## 情感设计

### 情感权重的含义

**0.0 - 0.3 (轻微)**:
- 日常琐事
- 中性观察
- 轻松氛围

**示例**:
```
今天的天气不错。
她决定出门走走。
```

---

**0.4 - 0.6 (中等)**:
- 有意义的时刻
- 轻度情感波动
- 值得记住的事件

**示例**:
```
书店的老板记得她喜欢什么类型的书。
这让她觉得有点温暖。
```

---

**0.7 - 1.0 (强烈)**:
- 关键转折点
- 强烈情感体验
- 深刻的内心冲突

**示例**:
```
她终于打开了那封信。
里面只有一句话："对不起。"
她哭了很久。
```

---

### 情感标签组合

**单一情感** (1个标签):
- 适合简单、直接的碎片
- 情感明确，易于理解

**复合情感** (2-3个标签):
- 适合复杂、微妙的碎片
- 更真实，更有层次

**示例**:
```
标签: [nostalgic, melancholic, warm]

她翻出了小时候的照片。
那时候的自己笑得很开心。
她也笑了，但眼眶有点湿。
```

---

### 情感节奏

**原则**: 避免情感疲劳

**建议比例**:
- 轻微情感: 50%
- 中等情感: 35%
- 强烈情感: 15%

**为什么**: 如果所有碎片都是强烈情感，玩家会麻木；如果都是轻微情感，玩家会觉得无聊。

## 常见错误

### 错误1: 过度解释

❌ **错误**:
```
她看着窗外的雨，想起了童年时和妈妈一起躲雨的场景。
那时候她还很小，妈妈总是保护她。
现在妈妈不在了，她感到很孤独。
她希望能再见妈妈一面。
```

✅ **正确**:
```
雨天。
她想起了妈妈。
```

**为什么**: 第一个版本解释了所有情感和背景，剥夺了玩家的想象空间。第二个版本留白，让玩家自己填补。

---

### 错误2: 打破观察关系

❌ **错误**:
```
她转过身，看着你。
"你一直在看着我吗？"她问。
```

✅ **正确**:
```
她转过身，看向窗边。
停顿了一会儿，又转回去了。
```

**为什么**: 角色不应该直接感知到玩家的存在。

---

### 错误3: 情感宣泄

❌ **错误**:
```
她非常非常难过！
她觉得整个世界都抛弃了她！
她不知道该怎么办！
```

✅ **正确**:
```
她坐在地上。
很久没有动。
天黑了，她也没有开灯。
```

**为什么**: 用行为和细节暗示情感，比直接宣泄更有力量。

---

### 错误4: 缺乏具体性

❌ **错误**:
```
她今天过得很不好。
发生了很多糟糕的事情。
她希望明天会好一点。
```

✅ **正确**:
```
公交车开走了，她没赶上。
咖啡洒在了新买的书上。
钥匙找了半个小时才找到。
```

**为什么**: 具体的细节比抽象的描述更有画面感和真实感。

---

### 错误5: 时态混乱

❌ **错误**:
```
她走进房间，看到桌上放着一封信。
她正在打开信，读着里面的内容。
她会感到很惊讶。
```

✅ **正确**:
```
她走进房间，看到桌上放着一封信。
她打开了信，读了里面的内容。
她愣住了。
```

**为什么**: 保持时态一致，避免跳跃。

## 设计流程

### 第1步: 确定叙事目标

**问自己**:
- 这个碎片要传达什么？
- 玩家看完后应该有什么感受？
- 这个碎片在整体故事中的位置？

**输出**: 一句话的碎片概要

**示例**: "揭示角色对过去的怀念，营造淡淡的忧伤氛围"

---

### 第2步: 选择碎片类型

根据叙事目标选择最合适的类型：
- 需要具体场景 → Scene
- 需要展现关系 → Dialogue
- 需要情感锚点 → Object
- 需要内心刻画 → Emotion

---

### 第3步: 写初稿

**技巧**:
1. 先写长版本（不限字数）
2. 删除所有解释性文字
3. 删除所有形容词和副词
4. 保留最核心的细节
5. 压缩到目标字数

---

### 第4步: 设置解锁条件

**考虑因素**:
- 内容的私密程度 → 亲密度要求
- 与其他碎片的关系 → 前置碎片
- 氛围的时间依赖 → 时间范围

---

### 第5步: 标注情感

**步骤**:
1. 选择1-3个情感标签
2. 评估情感权重（0.0-1.0）
3. 确保情感与内容匹配

---

### 第6步: 审查与迭代

**检查清单**:
- [ ] 字数在50-200字之间
- [ ] 使用第三人称过去时
- [ ] 没有直接解释
- [ ] 没有打破观察关系
- [ ] 有具体细节
- [ ] 情感标签准确
- [ ] 解锁条件合理
- [ ] 符合角色性格

---

### 第7步: 实现与测试

1. 使用 `generate_fragment.gd` 生成JSON文件
2. 使用 `validate_fragments.gd` 验证格式
3. 在游戏中实际测试
4. 收集反馈并迭代

---

## 示例分析

### 示例1: 优秀的Scene碎片

```
咖啡店的角落，她坐了一下午。
窗外的树叶从绿变黄，又从黄变红。
她点的咖啡早就凉了。
```

**分析**:
- ✅ 具体场景（咖啡店角落）
- ✅ 时间流逝的暗示（树叶颜色变化）
- ✅ 细节（咖啡凉了）暗示她沉浸在思考中
- ✅ 没有解释她在想什么，留白
- ✅ 字数适中（47字）

**情感标签**: [melancholic, contemplative]  
**情感权重**: 0.5  
**适合亲密度**: 30-50

---

### 示例2: 优秀的Dialogue碎片

```
"你最近还好吗？"邻居问。
"嗯，还好。"她回答。
其实她也不知道自己好不好。
```

**分析**:
- ✅ 简短的对话
- ✅ 揭示角色的内心状态（困惑、迷茫）
- ✅ 对话与内心的对比产生张力
- ✅ 没有过度解释
- ✅ 字数适中（38字）

**情感标签**: [confused, lonely]  
**情感权重**: 0.6  
**适合亲密度**: 40-60

---

### 示例3: 优秀的Object碎片

```
旧书签还夹在那本书里。
上面的字迹已经模糊了。
她记得那是谁送的，但不记得是什么时候了。
```

**分析**:
- ✅ 物品作为情感载体（书签）
- ✅ 时间流逝的暗示（字迹模糊）
- ✅ 记忆的不完整性（记得人，忘了时间）
- ✅ 怀旧氛围
- ✅ 字数适中（44字）

**情感标签**: [nostalgic, melancholic]  
**情感权重**: 0.5  
**适合亲密度**: 50-70

---

### 示例4: 优秀的Emotion碎片

```
有时候她会想，如果当初选择了另一条路会怎样。
但这种想法总是很快就消失了。
因为没有答案。
```

**分析**:
- ✅ 直接描述内心思考
- ✅ 展现角色的理性和接受
- ✅ 简洁有力的结尾
- ✅ 没有过度煽情
- ✅ 字数适中（48字）

**情感标签**: [contemplative, resigned]  
**情感权重**: 0.7  
**适合亲密度**: 60-80
